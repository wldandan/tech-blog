# "写代码这件事，我的经验不管用了"——Simon Willison 对 AI 时代的冷思考


> Simon Willison是那种你每次看他的东西都会有所收获的人。作为Datasette的作者和独立研究员，他大概是目前最清醒的AI编程实践者之一。今年4月，他上了Lenny Rachitsky的播客，聊了近两个小时，覆盖了从"**写代码的11月拐点**"到"**新西兰鸮鹦鹉**"之间的几乎所有话题。
>
> 我认真扒了一遍，挑出了最值得关注的5个洞见。有些会让你反思自己的工作方式，有些则可能让你对 AI 编程这件事的认知发生微妙但重要的转变。


# 一、11月拐点：代码"基本都能用"的那个时刻

Simon把2025年11月称为**AI编程的拐点**。

那一个月，**GPT-5.1和Claude Opus 4.5相继发布**。两者在编码能力上相比前代都只是"渐进提升"，但Simon的论点是，**这个渐进提升正好跨过了一个关键阈值**——以前AI写的代码"大部分时候能用，但你得盯得很紧"；11月之后，变成了"**几乎每次都能做到你说的那样**"。

> "现在你可以起一个coding agent，说'给我做一个Mac应用'，你拿到的不会是以前那种跑不起来的bug堆。"

这个转变听起来很小，但Simon认为它意味着：**写代码这件事的单位成本，从"小时"变成了"分钟"**。整个软件工程的时间感知被重新校准了。

# 二、软件工程师是"先遣部队"

Simon的一个核心观察是：**软件工程师是其他信息工作者的风向标。**

理由很简单：代码是AI最擅长处理的领域 —— 结果对错是二元的，编译通过就是通过，测试跑得通就是跑得通。用Simon的话说，"如果写篇论文、准备一份诉讼文件，你根本没法那么快判断它到底做得好不好"。

但软件工程师正在经历的这些 —— **职业路径怎么走、团队怎么协作、时间估算怎么搞** —— 迟早会轮到律师、医生、咨询师。Simon提到一个数据：**AI幻觉相关法律案件数据库已经收录了1,228起案件**。律师群体正在大量使用AI，然后被幻觉坑得很惨。

# 三、"负责任的Vibe Coding"

Simon对vibe coding的态度很务实。他的原则是：

> **如果代码只有你自己用，go wild。一旦你要把它交付给别人——别人的数据、别人的利益可能受bug影响——你就得踩刹车。**

这条线划得很清楚。问题不在于用不用AI，而在于**谁承担后果**。你自己玩随便造，但一旦涉及他人，传统的工程纪律——测试、review、灰度发布——一样不能少。

# 四、瓶颈从"写"移到了"测"

这是我觉得全篇最有价值的一个观点。

Simon的论证是：以前开发一个功能，**瓶颈在"实现"**——出spec，等三周，团队回来给你一个版本。现在可能三个小时就拿到了。所以瓶颈移到了哪里？

**移到了"验证"。**

> "任何做过产品的人都知道，你的初始想法永远是错的。重要的是证明它、测试它。"

Simon现在的做法是：**任何一个功能，先做三个不同方向的原型。** 因为UI原型现在是免费的 —— ChatGPT和Claude能直接给你生成一个高保真交互界面。以前这需要一个设计师花几天，现在只需要一段文字描述。

但问题来了：三个方案摆在面前，你怎么判断哪个最好？Simon说自己也没有确定的答案，但他猜测这会是**老派的用户可用性测试重新回归的地方**。

# 五、投资自己的agency

ThoughtWorks最近召集了一群工程VP做了个闭门讨论，得出一个有趣的分层结论：

- **资深工程师**：AI放大他们的能力 —— 知道该让AI做什么，也知道怎么判断AI的输出对不对
- **新手工程师**：AI解决了大量onboarding问题 —— 不会的代码让agent写就行
- **中间的**：**最危险。** 你的技术能力还不够做高级的架构判断和代码审查，但你的入门优势又被 AI 抹平了

Simon给中间层的人的建议是：**别害怕技能退化。你要刻意地去用它，去想"这个工具怎么让我变得更好"。** 核心不是你会写多少代码，而是你能不能用它去接更野心勃勃的项目。

他还提到了一个反复出现的词——**"agency"（自主性）**。Simon 认为AI永远不会有真正的agency，因为它没有人类的动机。所以**最好的投资是投资你自己的agency**：用这项技术让你把事做得更好、做以前做不了的事。

# 写在最后

Simon这期播客没什么大词和宏大叙事，但每个观点都来自切实的日常实践。他的核心态度可以总结为：**拥抱变化、保持清醒、对自己的输出负责。**

如果你只记住三句话：

1. **"Vibe coding给自己用没问题，给别人用得负责"**
2. **"瓶颈已经从'写'移到了'测'——你的判断力比以前更值钱"**
3. **"投资你自己的agency，因为AI永远不会有"**
